# FAQ and Themes

This context presents event FAQs and hackathon themes within a decorative illustrated scene.

## Language

**Scene Asset**:
Non-semantic artwork that establishes the page environment or atmosphere, including scenery, set dressing, and decorative effects.
_Avoid_: Background content, decorative UI

**Content Overlay**:
Semantic, user-facing information and controls placed above the scene, including FAQ entries, actions, and theme descriptions.
_Avoid_: Foreground asset, baked-in copy
